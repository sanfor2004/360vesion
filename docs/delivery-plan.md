# Delivery Plan

## Goal

Deliver a reproducible local 360Vision workspace with portable JSON projects,
processed local media, panorama authoring, synchronized room/map navigation, and
no credential or publication layer.

## Milestones

1. Local storage and direct dashboard/Studio/Viewer access.
2. Panorama, hotspot, and multi-floor map authoring.
3. Responsive and accessible Studio/Viewer polish.
4. Complete package import/export and documented backup/restore.

## Handoff

Provide source, documentation, demo assets, validation results, and backup
instructions. Do not commit runtime tour JSON, uploads, generated builds, logs,
reports, screenshots, environment overrides, or credentials.

Local setup is `npm install`, `npm run dev`, then
`http://localhost:3000/dashboard`. No environment configuration is required.
