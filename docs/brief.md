# Product Brief

360Vision is a dependable, single-owner local application for creating and
viewing interactive 360° real-estate tours. It does not have authentication,
profiles, visibility states, publication workflows, or a public gallery.

## Core experience

- My work lists every project saved on this device.
- Studio authors scenes, camera framing, hotspots, and optional multi-floor maps.
- Viewer opens any complete local project directly.
- Autosave writes portable, human-readable JSON under `data/tours/`.
- Save as and JSON download provide lightweight local portability.

Panorama positions are angular yaw/pitch values. Floor-plan positions are
percentages. Maps are optional and the compact room strip remains independent.

## Out of scope

- Accounts, roles, sessions, profiles, permissions, and collaboration
- Draft/public/unlisted states, publishing, discovery feeds, and view analytics
- Hosted sharing, embeds, SEO indexing, payments, and cloud asset billing
- Automatic plan generation and GPS navigation

## Success criteria

- Projects can be created, edited, saved, reopened, copied, and viewed locally.
- Uploaded assets and JSON survive restart and backup/restore.
- Every navigation method keeps room, floor, and current map point synchronized.
- Studio and Viewer work at desktop and mobile sizes.
