# 360Vision Project Documentation

This folder is the working source of truth for product scope, implementation, quality, and delivery.

## Documents

- [Brief](brief.md) — product purpose, users, scope, and success criteria.
- [Technical plan](technical-plan.md) — architecture, data model, implementation phases, and engineering decisions.
- [Validation plan](validation-plan.md) — automated, functional, visual, and release checks.
- [Delivery plan](delivery-plan.md) — milestones, artifacts, handoff, and deployment readiness.
- [Figma UI/UX specification](figma-ui-ux-spec.md) — frames, reusable components, prototype flows, and acceptance criteria for the product design file.
- [UI components](ui-components.md) — shared site primitives, usage examples, and contribution rules.
- [Project status](project-status.md) — implemented capability, remaining work, and release priorities.
- [Brand guide](../BrandGuide.md) — logo, palette, interface language, and accessibility rules.
- [References](references/README.md) — index for screenshots, plans, brand files, examples, and other materials supplied by the user.

## Maintenance

Update these documents when scope or architecture changes. Put new reference materials inside `docs/references/` and record their purpose in its index.
