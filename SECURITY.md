# Security Policy

## Supported Versions

Security updates are handled on the default branch.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Report security concerns privately to the maintainers using the repository security advisory feature after the project is published on GitHub. If advisories are not enabled yet, contact the repository owner directly.

Include:

- A description of the issue.
- Steps to reproduce it.
- The potential impact.
- Any suggested fix or mitigation.

Maintainers should acknowledge reports as soon as possible and avoid disclosing details publicly until a fix or mitigation is available.
