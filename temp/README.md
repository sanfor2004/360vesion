# Temporary diagnostics

All generated builds, logs, traces, screenshots, and debugging reports belong
under this directory instead of the repository root.

- `temp/.next/` — Next.js build output, development traces, and runtime logs.
- `temp/cache/` — generated compiler caches.
- `temp/logs/` — manually captured application or tool logs.
- `temp/reports/` — debugging and validation reports.
- `temp/screenshots/` — temporary visual-check captures.

The generated contents are ignored by Git. Only this guide and directory
placeholders are versioned.
